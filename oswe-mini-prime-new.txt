## Enhancement strategy (brief) 💡

- Build a read-only in-memory metadata index sorted by the required ordering.
- Build inverted indexes for `actor_id` and `action`.
- Use binary search on a `created_at` array to get a tight index range for timestamp filtering.
- For filter combinations, intersect sorted position-lists (two-pointer) instead of scanning from the beginning (this eliminates worst-case deep scans).
- Always read payloads from disk per-event via `seek` + `read` + `json.loads`.

## Baseline bottlenecks addressed 🛠️

- Eliminated deep linear scans for deep-offset pages by using binary search + inverted indexes (improves tail latency).
- Reduced connection churn with per-thread cached SQLite connection.
- Preserved the required disk-read behavior but reduced the number of rows scanned to find matching rows.
